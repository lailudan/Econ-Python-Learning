## 2. 机器学习的三大步骤（大象进冰箱理论）[00:15:17]

要把“大象塞进冰箱”，机器学习只需要三步：
1.  **定义一个函数集 (Model)**：确定你要找的 Function 长什么样（比如线性函数或复杂的神经网络）[00:11:48]。
2.  **定义评价准则 (Loss)**：通过训练数据判断一个 Function 是“好”还是“不好” [00:13:00]。
3.  **寻找最优函数 (Optimization)**：使用高效算法（如梯度下降）从万千 Function 中挑出表现最好的那一个 [00:14:09]。

## 4. 不同的学习场景 (Learning Scenarios) [00:36:12]

根据手头数据的“含金量”决定使用哪种情境：

* **监督学习 (Supervised Learning)**：Learning from teacher。有大量的输入及其对应的标签（Label）[00:34:00]。
* **半监督学习 (Semi-supervised)**：只有少量带标签数据，但有大量不带标签的数据 [00:25:15]。
* **迁移学习 (Transfer Learning)**：利用不相关任务的知识来辅助当前任务（比如用猫狗分类的知识帮你看医学影像）[00:25:59]。
* **无监督学习 (Unsupervised)**：机器“无师自通”。如词向量表示、AI 绘画生成 [00:26:45]。
* **强化学习 (Reinforcement Learning)**：Learning from critics。没有正确答案，只有环境给出的“奖励/惩罚”（如 AlphaGo 自我对弈）[00:31:39]。

## 机器学习深究：为什么机器学到的“意思”是一串向量（数字）？

> **课程出处**：[ML Lecture 0-1: Introduction of Machine Learning](https://www.youtube.com/watch?v=CXgbekl66jc)
> **关键时间戳**：[00:26:45] (Unsupervised Learning 部分)

在李宏毅老师的 PPT 中，当提到无监督学习（Machine Reading）时，出现了一个奇特的现象：机器读了大量的文章后，把“Apple”这个词输进去，函数（Function）输出的是带问号的**一串绿色圆点** [00:26:45]。

**这串圆点就是向量（Vector），本质上是一串数字。**

### 1. 为什么“意思”不能直接用文字表示？

我们人类理解“Apple”的意思是：一种红色的、甜的、可以吃的水果。或者是一家科技公司。

但是，对计算机来说：
* 文字“A-p-p-l-e”只是一串无意义的字符编码（如 ASCII 或 Unicode）。
* 如果用文字解释文字（比如查字典），机器只会陷入无限循环，无法进行数学运算。

### 2. 向量：为词语“安家”的坐标系统

在机器学习中，我们给每一个词语都在一个**高维空间**里找到一个唯一的坐标。这个坐标，就是词向量。

你可以把它想象成一个拥有成百上千个维度的立体空间：

* **第 1 维 (维度可能代表“是否是食物”)**：Apple在这个维度上的数字可能是 `0.9`（非常像食物），而“Car”可能是 `0.0`。
* **第 2 维 (是否是科技公司)**：Apple在这个维度上可能是 `0.8`（很像公司），“Banana”可能是 `0.1`。
* **第 N 维 (是否代表红色)**：...

当机器读了成千上万篇文章后，它通过计算每个词在不同上下文中的出现频率和位置（无监督学习），会自动在这个高维空间里，把“意思相近”的词，放在“空间位置”相近的地方。

### 3. 数学运算的力量：让机器“理解”语义

一旦词语变成了向量（数字），奇迹就发生了。机器就可以用**线性代数**来做语义推断了。

例如：
* **语义相似度**：计算两个向量之间的夹角余弦值（Cosine Similarity）。夹角越小，说明两个词的意思越近（比如“Apple”和“iPhone”在某些上下文里会靠得很近）。
* **语义类比 (非常经典的例子)**：
    $$Vector(\text{'King'}) - Vector(\text{'Man'}) + Vector(\text{'Woman'}) \approx Vector(\text{'Queen'})$$
    机器能计算出，“King”之于“Man”，就像“Queen”之于“Woman”。这种抽象的语义关系，完全是通过对数字（向量）的加减法实现的。

### 总结

对机器来说，文字的“意思”不是抽象的概念，而是它在“万词空间”中的**数学坐标** [00:27:10]。这个坐标（向量），就是它通过阅读大量文本，总结出来的关于这个词的最核心的特征描述。
