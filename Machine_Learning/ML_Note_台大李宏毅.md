## 2. 机器学习的三大步骤（大象进冰箱理论）[00:15:17]

要把“大象塞进冰箱”，机器学习只需要三步：
1.  **定义一个函数集 (Model)**：确定你要找的 Function 长什么样（比如线性函数或复杂的神经网络）[00:11:48]。
2.  **定义评价准则 (Loss)**：通过训练数据判断一个 Function 是“好”还是“不好” [00:13:00]。
3.  **寻找最优函数 (Optimization)**：使用高效算法（如梯度下降）从万千 Function 中挑出表现最好的那一个 [00:14:09]。

## 3. 核心任务分类 (Tasks)

| 任务类型 | 输出特征 | 实际案例 [00:16:33] |
| :--- | :--- | :--- |
| **回归 (Regression)** | 输出是一个数值 (Scalar) | PM2.5 预测、股票走势、健康经济支出 |
| **分类 (Classification)** | 做选择题 (Binary 或 Multi-class) | 垃圾邮件拦截、新闻自动分类、疾病诊断 |
| **结构化学习 (Structured)** | 输出复杂物件（序列、图等） | 语音识别、机器翻译、人脸关键点标注 |

## 4. 不同的学习场景 (Learning Scenarios) [00:36:12]

根据手头数据的“含金量”决定使用哪种情境：

* **监督学习 (Supervised Learning)**：Learning from teacher。有大量的输入及其对应的标签（Label）[00:34:00]。
* **半监督学习 (Semi-supervised)**：只有少量带标签数据，但有大量不带标签的数据 [00:25:15]。
* **迁移学习 (Transfer Learning)**：利用不相关任务的知识来辅助当前任务（比如用猫狗分类的知识帮你看医学影像）[00:25:59]。
* **无监督学习 (Unsupervised)**：机器“无师自通”。如词向量表示、AI 绘画生成 [00:26:45]。
* **强化学习 (Reinforcement Learning)**：Learning from critics。没有正确答案，只有环境给出的“奖励/惩罚”（如 AlphaGo 自我对弈）[00:31:39]。

---

## 5. 核心洞察

> **“如果能做监督学习，就不要去做强化学习。”** [00:37:07]
> 强化学习虽然很酷，但在有标签数据可用的情况下，监督学习通常更高效、更稳定。
