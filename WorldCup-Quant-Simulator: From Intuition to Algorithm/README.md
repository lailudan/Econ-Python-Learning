# ⚽ WorldCup-Quant-Simulator: From Intuition to Algorithm

## 📌 Project Overview
本项目旨在通过 Python 从零构建一个体育赛事的量化分析模型。初衷并非为了赌博盈利，而是将现实世界中的高方差赛事（如世界杯）作为概率统计的实战沙盘。

传统的体育投注往往依赖于球迷的“主观剧情推演”和“情绪消费”。本项目试图打破这种定势，拒绝陷入一上来就搞全量数据和机器学习的“宏大叙事”。我将从 **MVP（最小可行性产品）** 起步，跑通“获取静态数据 -> 构建数学计算 -> 输出概率与期望值”的闭环，用以寻找庄家赔率中隐藏的**“错误定价（Value Betting / +EV）”**。

## 🚀 The MVP Execution Plan: 第一代“印钞机”原型

为了避免过度工程化，本项目的 V1.0 版本将严格遵循以下三个实战阶段：

### Phase 1: 搭建兵工厂与获取“免费弹药” (Environment & Data)
不要一上来就花钱购买昂贵的实时 API，先利用静态历史数据将底层逻辑跑通。
* **开发环境**: 强烈建议使用 **Jupyter Notebook**。它的交互式特性极其适合数据分析，可逐行运行代码并实时查看中间算力输出，是查错与试水的神器。 - 基本都完成
* **核心算力库**: 仅需三个最基础的 Python 包：
    * `pandas`: 处理表格数据的绝对霸主。
    * `numpy`: 负责底层矩阵运算与科学计算。
    * `scipy`: 直接调用现成的统计学分布公式（如泊松分布）。
* **金矿数据源**: 利用体育量化圈的开源宝藏网站 [football-data.co.uk](https://www.football-data.co.uk/)。它免费提供十几个赛季主流联赛的 CSV 历史数据，包含比分、进球时间以及各大主流庄家（Bet365, William Hill）的赔率，是进行回测（Backtesting）的绝佳语料。

### Phase 2: 手搓第一台“概率计算器” (Probability Engine)
将下载好的 CSV 注入代码，构建算力核心。MVP 阶段暂不考虑天气或裁判因素，纯粹基于两队历史攻防实力。
* **计算攻防因子**: 使用 `pandas` 算出联赛平均进球数。随后计算主队（如日本队）的“主场攻击力”（进球率高于均值的比率）和客队（如瑞典队）的“客场防守力”。
* **计算预期进球数 (λ)**: 
    主队 λ = 主队攻击力 × 客队防守力 × 联赛平均主场进球
* **泊松分布运算**: 摒弃手写复杂的阶乘公式，直接调用 `scipy`。

```python
from scipy.stats import poisson

# 假设算出日本队预期进球 1.4 个，瑞典队预期进球 1.1 个
lambda_jp = 1.4
lambda_sw = 1.1

# 计算日本队单场精准打进 2 个球的概率
prob_jp_2 = poisson.pmf(2, lambda_jp)
print(f"日本队进2球的概率为: {prob_jp_2:.2%}")
```

### Phase 3: 构建概率矩阵与寻找“价值洼地” (+EV Detection)
这是见证奇迹的最后一步，将两支球队进 0 到 5 个球的概率交叉相乘，生成一个 6×6 的比分概率矩阵。
* **推算胜平负**: 将矩阵中所有“主队进球 > 客队进球”的单元格概率相加，即得出系统的真实胜率预测。
* **逆向转化与 EV 侦测**: 假设代码得出日本队胜率为 35%。此时读取 CSV 中的庄家赔率（例如 3.50）。庄家赔率暗示的胜率为 1 / 3.50 ≈ 28.5%。
* **触发警报**: 35% (真实模型) > 28.5% (市场暗示)。警报触发，这意味着市场严重低估了日本队，这是一个具备正向期望值（+EV）的“价值洼地”。

$$EV = (P_{win} \times Profit) - (P_{loss} \times Loss)$$
### 一个极端的抛硬币例子

假设有人找你玩抛硬币，规则如下：

* **抛到正面**：你赢 **$150**。
* **抛到反面**：你输 **$100**（即你的本金）。

普通的硬币正反面概率都是 **50%**。我们来算一下这个游戏的 EV：

* $P_{win} = 0.50$ (50%)
* $Profit = 150$
* $P_{loss} = 0.50$ (50%)
* $Loss = 100$

$$EV = (0.50 \times 150) - (0.50 \times 100)$$

$$EV = 75 - 50$$

$$EV = 25$$

## 🧮 Mathematical Core
本项目的底层运算逻辑建立在经典的数学模型之上：

**进球概率预测：泊松分布 (Poisson Distribution)**
假设球队在一场比赛中的预期进球数为 λ，那么该队精准打进 x 个球的概率公式为：
P(x) = (λ^x * e^-λ) / x!

## 🧠 Trading Psychology & Mental Accounting
**"Hedging the Downside with Fine Dining"**
本项目在实操策略上深度结合了行为金融学中的“心理账户（Mental Accounting）”概念，采用“右侧交易”与“价值投资”结合的对冲打法：
1.  **确定性溢价**：利用顺风局（如美国队）的绝对压制力建立底仓，锁定回血的确定性。
2.  **方差博弈**：用极小的试错成本（+EV 警报提示）去押注市场错误定价的高方差剧情（如日本队逆风逼平/反杀强敌）。
3.  **下行保护**：即使方差局未如预期收敛，最大的潜在沉没成本在心理账户中已被具象化并隔离为“一顿纽约的 Fine Dining”。这种极其理性的头寸管理，保证了在高波动性博弈中的极高“情绪投资回报率（ROI）”与决策纪律。
