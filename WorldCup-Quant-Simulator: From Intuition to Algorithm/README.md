⚽ WorldCup-Quant-Simulator: From Intuition to Algorithm
📌 Project Overview
本项目旨在通过 Python 从零构建一个体育赛事的量化分析模型。初衷并非为了赌博盈利，而是将现实世界中的高方差赛事（如世界杯小组赛）作为概率统计的实战沙盘。

传统的体育投注往往依赖于球迷的“主观剧情推演”和“情绪消费”。本项目试图打破这种定势，通过抓取底层赛事数据、建立泊松分布模型，并利用蒙特卡洛模拟跑出成千上万个平行宇宙的赛果，从而精准寻找庄家赔率中隐藏的“错误定价（Value Betting / +EV）”。

🗺️ Roadmap: The "From Scratch" Architecture
整个项目的开发路径分为以下五个核心模块：

Phase 1: Data Pipeline (数据基座搭建)
拒绝使用宏观的新闻或赛果数据。接入 API-Football 或 StatsBomb 等接口，编写爬虫抓取底层的事件数据：预期进球数（xG）、危险进攻转化率、控球区域分布等，并使用 Pandas 完成数据的清洗与结构化。

Phase 2: Probability Modeling (泊松分布建模)
将两支球队的历史攻防数据输入模型，计算出单场比赛的预期进球数（λ）。据此生成一个包含所有可能比分（1-0, 2-1, 0-0 等）的精确概率矩阵。

Phase 3: Monte Carlo Simulations (蒙特卡洛模拟)
针对高方差的“小组赛连环套（石头剪刀布局）”，程序不会停留在单场胜负的计算。利用建好的概率矩阵，在内存中将剩余赛事模拟运行 10,000 次，比对积分与净胜球，输出球队最终出线的真实概率（例如：18.42%）。

Phase 4: Expected Value (+EV) Detection (价值洼地监测)
实时抓取主流庄家的盘口赔率，将其逆向转化为“隐含概率”。将庄家概率与蒙特卡洛模拟得出的“真实概率”进行对比。当真实概率大于庄家隐含概率时，程序自动触发正向期望值（+EV）报警。

Phase 5: Bankroll Management (仓位管理模块)
为了对抗博弈中的人性弱点，引入数学法则进行严格的下行风险管理。计算出单次下注应占总资金池的精确百分比，确保资金在长期高频的博弈中稳健增长。

🧠 Trading Psychology & Mental Accounting
"Hedging the Downside with Fine Dining"
本项目在实操策略上结合了行为金融学中的“心理账户”概念。在早期的原型测试中，策略采用了“右侧交易”与“价值投资”结合的对冲打法：

确定性溢价：重仓具备绝对压制力的顺风局（如美国队），锁定保底回血的确定性。

方差博弈：用极小的试错成本押注市场错误定价的高方差局（如日本队逼平强敌）。

下行保护：即使方差局未如预期收敛，最大的沉没成本在心理账户中已被具象化为“一顿纽约的 Fine Dining”，从而保证了测试过程中的极高“情绪投资回报率（ROI）”与决策理智。
